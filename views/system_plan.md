# レポート用システム設計書

## 共通の保存方法と操作

各システムのデータは SQLite データベースの別々のテーブルに保存する。初回作成時に各テーブルへ5人分の初期データを登録する。以後は件数を固定せず、画面からメンバーを追加・変更・削除できる。変更はデータベースに保存し、アプリケーションの再起動後も保持する。ID は各テーブル内で一意に採番し、追加時に既存の ID と重複しないようにする。YouTube チャンネルの URL は未確認の場合、空欄（NULL）で保存し、後から登録・変更できる。

## 1. ミリプロメンバー管理システム

### 対象

ミリプロに所属する配信者の基本プロフィール、活動開始日、YouTubeチャンネル、担当カラーを管理する。利用者は一覧からメンバーを選び、詳細情報を確認できる。

### ページ遷移

```text
トップページ
  └─ ミリプロメンバー一覧
       ├─ メンバー登録 → 登録完了 → 一覧
       └─ メンバー詳細
            ├─ メンバー変更 → 更新完了 → 詳細
            ├─ メンバー削除確認 → 削除完了 → 一覧
            └─ 一覧へ戻る
```

### スキーマ

| 項目名 | 型 | 内容 |
| --- | --- | --- |
| id | 整数 | メンバーを一意に識別するID |
| name | 文字列 | 活動名 |
| generation | 文字列 | 所属ユニット・期 |
| debut_date | 日付 | 活動開始日 |
| channel_url | 文字列 | YouTubeチャンネルのURL |
| color | 文字列 | 担当カラー |
